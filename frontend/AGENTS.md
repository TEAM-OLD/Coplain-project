# frontend (React)

이 폴더에서 작업하는 모든 AI 에이전트는 루트의 `AGENTS.md`, `COWORK_RULE.md`와 함께 아래 규칙을 따른다. 소유자는 FE(서재욱)다.

## 구조

- 서버 요청은 한 곳(API 클라이언트 모듈)에서만 한다. 컴포넌트에서 직접 주소를 조합해 요청하지 않는다.
- API가 아직 없으면 `docs/api/`의 응답 예시로 목업 데이터를 만들어 쓰고, 목업은 한 폴더에 모아 둔다.
- 코드 편집기와 뷰어는 Monaco Editor(`@monaco-editor/react`)를 쓴다.

## 반드시 지킬 것

- 서버 데이터를 쓰는 화면은 로딩, 성공, 실패(그리고 빈 상태)를 모두 처리한다.
- 이전 요청의 응답이 늦게 도착해 현재 화면을 덮어쓰지 않게 한다.
- LLM이 만든 텍스트(질문, 피드백)는 HTML로 직접 넣지 않는다(`dangerouslySetInnerHTML` 금지).
- 외부 AI·음성 API를 프론트엔드에서 직접 호출하지 않는다. API 키를 프론트엔드 코드에 넣지 않는다.
- 타이머, 이벤트 리스너, SSE 연결(`EventSource`), 녹음(`MediaRecorder`)은 화면을 떠날 때 정리한다.
- 마이크 사용은 HTTPS 또는 localhost에서만 동작한다.
