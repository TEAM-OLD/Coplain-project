# backend (Spring Boot)

이 폴더에서 작업하는 모든 AI 에이전트는 루트의 `AGENTS.md`, `COWORK_RULE.md`와 함께 아래 규칙을 따른다. 소유자는 BE(김민서)이며, DB 마이그레이션과 AI 파이프라인 코드는 Lead 소유다.

## 구조

- 계층: Controller(요청·응답) → Service(로직, 트랜잭션) → Repository(DB 접근)
- 요청·응답에는 DTO를 쓴다. 엔티티를 응답으로 그대로 내보내지 않는다.
- 외부 서비스(LLM, TTS, STT, 메일)는 인터페이스 뒤에 두고, 개발용 mock 구현을 함께 둔다.

## 반드시 지킬 것

- 조회·수정·삭제 API는 요청한 사용자가 데이터의 소유자인지 확인한다(IDOR 방지).
- 트랜잭션 안에서 외부 API(LLM, TTS, STT, 메일)를 호출하지 않는다.
- 목록 조회에서 N+1 쿼리가 생기지 않게 한다. 필요하면 fetch join을 쓴다.
- 인증은 세션 쿠키 방식이다. 쿠키 인증 요청에는 CSRF 대응이 필요하다.
- 비밀번호는 해시로 저장하고, 규칙(숫자·특수문자 포함 8~20자)은 서버에서 다시 검증한다.
- 오류 응답은 `docs/api/`의 공통 오류 형식을 따른다(확정 후).
- DB 스키마 변경은 마이그레이션 파일로만 한다. 마이그레이션 추가·변경은 Lead 리뷰가 필수다.
